# Wazuh Detection Lab

## Autores
Samir Cuenca y Joshua Brazales

## Objetivo
Detectar la técnica MITRE ATT&CK T1046 - Network Service Scanning utilizando Wazuh, Sysmon y Nmap.

## Herramientas
- Ubuntu Server 24.04
- Wazuh 4.x
- Windows 11
- Sysmon
- Nmap

## Contenido
- Investigación del actor Sandworm.
- Implementación de Wazuh.
- Integración de Sysmon.
- Simulación de escaneo.
- Reglas de detección.
